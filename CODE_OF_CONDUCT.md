# Code of conduct

Treat contributors and users with respect. Discuss technical decisions on their merits, make feedback specific, and allow room for different experience levels and communication styles.

Harassment, discrimination, threats, personal attacks, and publishing another person's private information are not acceptable in project issues, pull requests, discussions, or other project spaces.

Maintainers may edit or remove inappropriate content and restrict participation when needed. Enforcement should be proportionate and consider the context and impact of the behavior.

To report a concern, contact a repository maintainer privately through a contact method on their GitHub profile. If no private channel is listed, ask for one without including sensitive details in a public issue.
